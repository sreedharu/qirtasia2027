# QIRT Asia 2027 Conference Website - AI Agent Memory

## Overview
This repository contains the official website for the 6th Quantitative InfraRed Thermography Asian Conference (QIRT Asia 2027), hosted in Singapore.

## Technical Architecture
- **Tech Stack**: HTML5, Vanilla CSS, JavaScript.
- **Pages**:
  - `index.html`: Main landing page (keynotes, venue, registration countdown, committee).
  - `pages/`: Subpages (call for papers, venue & travel, committee, schedule).
- **Styling**: `css/`, `styles.css` using modern glassmorphism, responsive CSS variables, dynamic navigation, and interactive animations.

## Deployment
- Hosted via GitHub Pages with custom domain (`CNAME`).
